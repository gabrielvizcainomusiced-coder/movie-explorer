# 🎬 Movie Explorer

A React application for searching and discovering movies using the TMDB API.

## Features

- ✅ Search movies by title
- ✅ Display popular movies on homepage
- ✅ View movie posters, ratings, and release dates
- ✅ Responsive design for mobile and desktop
- ✅ Loading states and empty state handling

## Tech Stack

- React 18
- Vite
- TMDB API
- CSS3

## Setup

1. Clone the repository
2. Install dependencies:
```bash
   npm install
```
3. Create a `.env` file and add your TMDB API key:
```
   VITE_TMDB_API_KEY=your_api_key_here
```
4. Run the development server:
```bash
   npm run dev
```

## API Key

Get your free API key from [The Movie Database (TMDB)](https://www.themoviedb.org/settings/api)
